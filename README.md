# QurbanKuy 🐐🐄

Sebuah sistem informasi digital yang dirancang untuk memfasilitasi, mengelola, dan memonitor proses ibadah kurban agar berjalan secara terstruktur dan transparan.

## 📝 Deskripsi Proyek
**QurbanKuy** hadir sebagai solusi digital untuk mengatasi kendala pencatatan dan pengelolaan hewan kurban. Sistem ini membantu panitia kurban maupun peserta (mudhohi) dalam melacak status hewan kurban, mulai dari proses pendaftaran, penyembelihan, hingga distribusi daging, sehingga seluruh rangkaian kegiatan dapat dipantau dengan jelas.

## ✨ Fitur Utama
* **Manajemen Data Kurban:** Pencatatan detail hewan kurban dan identitas peserta yang terintegrasi dengan basis data.
* **Verifikasi QR Code:** Sistem pemindaian QR Code untuk memverifikasi data dan status kurban secara cepat dan akurat.
* **Sistem Autentikasi & Antarmuka Intuitif:** Proses login yang aman dipadukan dengan desain UI/UX yang ramah pengguna.

## 👥 Tim Pengembang dan Pembagian Tugas
Proyek ini dibangun bersama tim dengan pembagian fokus pengerjaan sebagai berikut:
* **Partial Backend & QR System:** Saya bertanggung jawab pada sebagian pengerjaan *backend*, khususnya dalam merancang dan mengelola *database*, serta mengimplementasikan logika untuk sistem verifikasi menggunakan *QR Code*.
* **UI/UX & Login System:** Teman saya bertanggung jawab penuh atas perancangan desain visual (UI/UX), pengerjaan halaman *frontend*, serta integrasi sistem *login* dan fitur-fitur lainnya.

## 🛠️ Teknologi yang Digunakan
* **Frontend:** HTML, CSS, JavaScript
* **Backend:** PHP
* **Database:** MySQL
* **Fitur Tambahan:** Library pemindai QR Code.
